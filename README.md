# 🍳 Cooking Blog Web App

A responsive **Cooking Blog Web App** built with **React.js** and **Tailwind CSS**, designed to showcase recipes with a clean UI and smooth user experience.  

---

## 🚀 Features
- 📱 Responsive design (mobile, tablet & desktop friendly)  
- 🍲 Recipe/blog listing page  
- 📝 Detailed recipe/blog view  
- 🎨 Clean and modern UI  
- ⚡ Fast and lightweight with React.js  

---

## 🛠️ Tech Stack
- **React.js**  
- **Tailwind CSS**  
- **JavaScript (ES6+)**  
- **API Integration** (if used)
